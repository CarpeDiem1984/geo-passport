# GEO-паспорт бренда

Статический сайт New World: что Алиса AI говорит о брендах гостей.

## Как устроен доступ

При входе гость выбирает свой бренд и вводит пароль. Паспорт каждого бренда хранится в `data.js` в зашифрованном виде (AES-GCM, ключ из пароля через PBKDF2) и расшифровывается прямо в браузере. Без пароля содержимое паспорта не прочитать даже через исходный код страницы.

В репозитории нет ни открытых данных, ни паролей. Исходные данные и список паролей хранятся у агентства отдельно.

## Как обновить данные или добавить бренд

1. Поправить исходник данных (`source-data.js`) и при необходимости добавить пароль в `passwords.json`.
2. Собрать зашифрованный файл: `node build.js source-data.js passwords.json data.js`.
3. Положить новый `data.js` в репозиторий и поменять номер версии в `index.html` (`data.js?v=…`), чтобы браузеры не показывали старую копию.
